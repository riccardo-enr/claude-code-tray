# Quick Task: tmux-powerline usage segment

Implements SEED-008. Puts `62% 2h14m` on the left tmux status line, sourced from
the daemon that is already running -- no new poller, no new data source.

## Design (post-research, see SEED-008)

Three new pieces plus two edits:

1. **`core.fmt_countdown_short(secs)`** -- `7380 -> '2h3m'`, `840 -> '14m'`,
   `<=0 -> 'now'`. Third sibling of `fmt_countdown` / `fmt_countdown_wk`; the
   prose forms are too wide for a status bar.
2. **`core.statusline_text(pct, reset, now)`** -- `'62% 2h14m'`, `'91% 48m !'`.
   Pure, returns `None` when there is no percent (so the segment can hide rather
   than print a fake zero). `!` fires on `band()`'s fixed 90% line, not on the
   mutable `USAGE_THRESHOLD` badge setting, so glyph and colour agree.
3. **`claude-status.py`** -- root script, mirrors `claude-send.py`. Tries
   `core.query_snapshot()` (live, includes everything), falls back to reading
   `HISTORY_PATH` via `parse_history` + `latest_state` when the daemon is down.
   Prints one line with an inline `#[fg=...]` override in the yellow/red bands.
4. **`tmux/claude_usage.sh`** -- tmux-powerline segment, `run_segment()` contract.
5. **`install.sh`** -- symlink the new script; install the segment only when a
   tmux-powerline segments dir already exists.

## Decisions

- **Segment, not `status-left`.** This machine's `status-left` is owned by
  `erikw/tmux-powerline` (`tmux.conf:107`); overriding it would delete the
  user's whole powerline. Ship a segment, let the framework draw separators.
- **No cache.** `python3` + `import core` measured ~58ms; `status-interval` is
  2s and the sibling `git_status.sh` already forks git+awk+tmux every tick.
  Marked with a `ponytail:` note -- add mtime caching if it ever shows up.
- **Level thresholds, not projected exhaustion.** `band()` reuse is the lazy
  correct version; `project()`/`alert_due()` is the documented upgrade path.
- **Socket first, history fallback.** Both are zero-added-polling. Socket gives
  live numbers; history file is <=15s stale and survives a stopped daemon.

## Verification

`just selfcheck` stays green (new asserts for both pure functions, incl. the
None/absent-reset branches), `just lint` clean, and the segment renders live in
the user's actual tmux.
