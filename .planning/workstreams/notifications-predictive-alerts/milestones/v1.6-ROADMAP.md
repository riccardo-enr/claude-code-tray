# Milestone v1.6: TUI Polish

**Status:** ✅ SHIPPED 2026-07-24
**Phases:** 10
**Total Plans:** 3

## Overview

Turn the functional v1.5 Textual dashboard into a btop-inspired terminal
surface without changing its data source, polling model, or runtime dependency
boundary. The Python TUI now acts as the behavioral and visual reference for a
proposed Rust rewrite.

The planned work added threshold colors, gradient quota gauges, a taller trends
graph, styled live-session rows, and titled rounded panels. Follow-up work in
the same release used the available horizontal space for quota projections and
a Mon-Sun usage heatmap, added selected-session focus, preserved selection
across refreshes, hardened background work, and corrected the hourly trend
chart to graph usage increments instead of cumulative percentage means.

## Phase

### Phase 10: TUI Polish (btop-style)

**Goal:** Make the v1.5 plain-text `claude-tui.py` read like a btop-inspired
dashboard while keeping `claude_monitor.core` as the single source of every
formatted value.

**Depends on:** Phase 9 (Textual dashboard and daemon snapshot query)

**Requirements:** TUI-06, TUI-07, TUI-08, TUI-09, TUI-10

**Plans:** 3 plans

- [x] 10-01 — Usage-panel threshold bands and gradient gauges (TUI-06, TUI-07)
- [x] 10-02 — Decoded, height-colored trends graph (TUI-08)
- [x] 10-03 — Status-colored striped sessions and titled bordered panels (TUI-09, TUI-10)

**Outcome:**

- Both quota caps render as green-to-yellow-to-red gauges with proximity-colored
  percentage, reset, and burn-rate text.
- The trends panel decodes the existing core sparkline into a taller colored
  graph, preserving gaps and retaining the existing aggregate text.
- Session rows are status-colored and zebra-striped; all primary regions use
  titled rounded borders.
- The existing core/render boundary held: pure decisions and data shaping remain
  self-checkable in `claude_monitor.core`; Textual/Rich only apply presentation.

## Additional Release Work

- Per-cap projection or exhaustion ETA beside each quota gauge.
- Dashboard-parity Mon-Sun hourly usage heatmap in the trends panel.
- Focus the selected live session through the existing daemon/tmux path.
- Preserve selected session across automatic table refreshes.
- Keep daemon background work alive when a client disconnects.
- Chart trustworthy per-sample usage rises in clock-hour buckets instead of
  averaging cumulative rolling-window percentages.

## Milestone Summary

**Key decisions:**

- Keep fixed TUI color bands separate from the configurable tray badge threshold.
- Put assertable behavior in `core.py`; keep glyphs, colors, borders, and layout
  in `claude-tui.py`.
- Color gauge cells by position so every filled meter retains the btop
  green-to-yellow-to-red sweep.
- Reuse the existing projection and heatmap math instead of creating TUI-only
  calculations.
- Keep the Python Textual application as the reference implementation for the
  proposed Rust TUI rather than replacing it in place.
